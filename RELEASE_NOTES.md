# Antigravity Enhancer v3.4.1

## Changes

- Added `auto-repatch.js` and a limited-privilege Windows Scheduled Task (`AntigravityEnhancerAutoRepatch`) registered by the installer to automatically re-apply compatible, SHA-256 verified patches when an Antigravity IDE update overwrites `app.asar` (cleanly removed on Restore Original).
