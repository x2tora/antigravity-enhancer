## 主な機能

- **15言語UI・右クリックメニュー対応**: OS言語の自動検出と再起動不要の即時切替、自然なインライン文翻訳を提供します。
- **統合パッチ設定とカスタム用語集**: アプリ内更新、多言語変更履歴、カスタム用語集（未翻訳クリック入力・JSON入出力）、ショートカットを一元管理します。
- **モデルクォータ表示と72時間履歴**: 上部バーに `Gemini` / `Other` の5時間・週間残量と72時間推移グラフを表示します。
- **安全な復元とクロスプラットフォーム対応**: 元ファイルを無損失で保持しワンクリック復元可能。Windows GUI および macOS/Linux CLI インストーラーを提供します。

## インストール方法

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe) をダウンロードします。
2. インストーラーを起動し **パッチをインストール**（または **オリジナルに戻す**）をクリックすると完了後に自動で再起動します。

### macOS / Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```
