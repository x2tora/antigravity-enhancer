## Funkcje

- **15 języków i menu kontekstowe**: Automatyczne wykrywanie języka systemu, zmiana bez restartu i naturalne tłumaczenie zdań z linkami.
- **Ustawienia łatki i własny słownik**: Aktualizacje w aplikacji, wielojęzyczny dziennik zmian, własny słownik (JSON) i skróty.
- **Podgląd limitów i historia 72 h**: Wyświetla limity 5-godzinne i tygodniowe dla `Gemini` oraz `Other` z wykresami.
- **Bezpieczne przywracanie i wieloplatformowość**: Zachowuje oryginalne pliki, 2-etapowy instalator Windows oraz CLI dla macOS/Linux.

## Instalacja

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. Pobierz [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe).
2. Uruchom instalator i kliknij **Zainstaluj łatkę** (lub **Przywróć oryginał**). Antigravity uruchomi się ponownie automatycznie.

### macOS i Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```
