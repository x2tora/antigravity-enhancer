## Fitur Utama

- **15 Bahasa & Menu Konteks**: Deteksi otomatis bahasa sistem, ganti bahasa tanpa mulai ulang, dan terjemahan kalimat bertautan yang alami.
- **Pengaturan Patch Terpadu & Glosarium Kustom**: Pembaruan dalam aplikasi, catatan perubahan multibahasa, glosarium (JSON), dan pintasan.
- **Tampilan Kuota & Riwayat 72 Jam**: Menampilkan kuota 5 jam dan mingguan untuk `Gemini` dan `Other` beserta grafik tren.
- **Pemulihan Aman & Lintas Platform**: File asli tetap terjaga dengan pemulihan 1 klik; pemasang Windows 2 langkah dan CLI macOS/Linux.

## Pemasangan

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. Unduh [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe).
2. Jalankan pemasang lalu klik **Pasang patch** (atau **Pulihkan asli**). Antigravity akan mulai ulang otomatis.

### macOS & Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```

*Patch komunitas tidak resmi. Tidak berafiliasi dengan tim resmi Antigravity.*
