## Funktionen

- **15 Sprachen & Kontextmenüs**: Automatische Spracherkennung, Wechsel ohne Neustart und natürliche Übersetzung von Sätzen mit Links.
- **Einheitliche Patch-Einstellungen & Glossar**: In-App-Updates, lokalisierter Änderungsverlauf, eigenes Glossar (JSON) und Tastenkürzel.
- **Kontingentanzeige & 72h-Verlauf**: Zeigt 5-Stunden- und Wochenkontingente für `Gemini` und `Other` samt Verlaufsgrafik.
- **Sichere Wiederherstellung & Cross-Platform**: Verlustfreie Original-Sicherung, 2-Schritte-Windows-Installer sowie CLI für macOS/Linux.

## Installation

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. Laden Sie [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe) herunter.
2. Starten Sie das Setup und klicken Sie auf **Patch installieren** (oder **Original wiederherstellen**). Antigravity startet automatisch neu.

### macOS & Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```
