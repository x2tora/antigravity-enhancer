## Características

- **Localización en 15 idiomas y menús contextuales**: Detección automática del idioma del sistema, cambio sin reinicio y traducción natural de frases con enlaces.
- **Ajustes unificados y glosario personalizado**: Actualizaciones integradas, historial localizado, glosario editable con importación/exportación JSON y atajos.
- **Visor de cuota y 72 h de historial**: Muestra cuotas de 5 horas y semanales para `Gemini` y `Other` con gráficos de tendencia.
- **Restauración segura y multiplataforma**: Conserva los archivos originales con restauración en un clic; instalador gráfico para Windows y CLI para macOS/Linux.

## Instalación

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. Descarga [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe).
2. Ejecuta el instalador y haz clic en **Instalar parche** (o **Restaurar original**). Antigravity se reiniciará automáticamente.

### macOS y Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```

*Parche comunitario no oficial. No está afiliado al equipo oficial de Antigravity.*
