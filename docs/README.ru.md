## Возможности

- **15 языков интерфейса и контекстных меню**: Автоопределение языка ОС, переключение без перезапуска и естественный перевод фраз со ссылками.
- **Единые настройки и пользовательский глоссарий**: Обновления в приложении, локализованный журнал изменений, глоссарий (JSON) и горячие клавиши.
- **Индикатор квот и история за 72 ч**: Показывает 5-часовую и недельную квоту `Gemini` и `Other` со спарклайнами.
- **Безопасное восстановление и кроссплатформенность**: Сохранность оригинальных файлов, 2-шаговый установщик Windows и CLI для macOS/Linux.

## Установка

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. Скачайте [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe).
2. Запустите установщик и нажмите **Установить патч** (или **Восстановить оригинал**). Antigravity перезапустится автоматически.

### macOS и Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```

*Неофициальный патч сообщества. Не связан с официальной командой Antigravity.*
