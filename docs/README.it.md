## Funzionalità

- **15 lingue e menu contestuali**: Rilevamento automatico della lingua di sistema, cambio istantaneo senza riavvio e traduzione naturale di frasi con link.
- **Impostazioni patch unificate e glossario**: Aggiornamenti integrati, changelog localizzato, glossario personalizzato (JSON) e scorciatoie.
- **Visualizzazione quota e storico 72 ore**: Mostra le quote 5 ore e settimanali per `Gemini` e `Other` con grafici.
- **Ripristino sicuro e multipiattaforma**: Conserva i file originali, installer Windows in 2 passaggi e CLI per macOS/Linux.

## Installazione

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. Scarica [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe).
2. Avvia l’installer e fai clic su **Installa patch** (o **Ripristina originale**). Antigravity si riavvierà automaticamente.

### macOS e Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```
