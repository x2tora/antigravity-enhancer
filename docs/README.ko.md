## 주요 기능

- **15개 언어 UI 및 우클릭 메뉴 번역**: 한국어, 영어, 일본어, 중국어(간/번체), 스페인어, 프랑스어, 독일어, 러시아어, 포르투갈어(BR), 베트남어, 이탈리아어, 인도네시아어, 튀르키예어, 폴란드어를 지원하며 OS 언어 자동 인식과 재시작 없는 즉시 전환을 제공합니다.
- **통합 패치 설정 및 사용자 용어집**: 업데이트 확인, 다국어 변경 기록, 커스텀 용어집(미번역 클릭 자동 입력·JSON 가져오기/내보내기), 할당량 알림 및 단축키를 한 창에서 관리합니다.
- **모델 할당량 표시 및 72시간 기록**: 상단 바 및 입력창 배지에 `Gemini`와 `Other` 5시간/주간 잔여량을 표시하고 72시간 추이 그래프와 리셋 카운트다운을 제공합니다.
- **안전한 복구 및 크로스플랫폼 지원**: 원본 파일을 무손실 보존해 언제든 원클릭 복구할 수 있으며, Windows 2단계 GUI 설치기와 macOS·Linux CLI 설치기를 제공합니다.

## 설치 방법

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe)를 다운로드합니다.
2. 설치 프로그램을 실행하고 **패치 설치**(또는 **원본 복구**)를 누르면 완료 후 Antigravity가 자동 재시작됩니다.

### macOS 및 Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```
