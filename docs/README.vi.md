## Tính năng

- **Hỗ trợ 15 ngôn ngữ & menu chuột phải**: Tự nhận diện ngôn ngữ hệ thống, chuyển đổi tức thì không cần khởi động lại và dịch tự nhiên các câu chứa liên kết.
- **Cài đặt bản vá hợp nhất & từ điển tùy chỉnh**: Cập nhật trong ứng dụng, nhật ký đa ngôn ngữ, từ điển tùy chỉnh (JSON) và phím tắt.
- **Hiển thị hạn mức & lịch sử 72 giờ**: Theo dõi hạn mức 5 giờ và hàng tuần cho `Gemini` và `Other` kèm biểu đồ xu hướng.
- **Khôi phục an toàn & đa nền tảng**: Bảo toàn tệp gốc, trình cài đặt 2 bước trên Windows và trình cài đặt CLI cho macOS/Linux.

## Cài đặt

### Windows (`Antigravity-Enhancer-Setup.exe`)

1. Tải [`Antigravity-Enhancer-Setup.exe`](https://github.com/x2tora/antigravity-enhancer/releases/latest/download/Antigravity-Enhancer-Setup.exe).
2. Chạy trình cài đặt và nhấn **Cài đặt bản vá** (hoặc **Khôi phục bản gốc**). Antigravity sẽ tự động khởi động lại.

### macOS & Linux (`install.sh`)

```bash
tar -xzf Antigravity-Enhancer-v4.1.0-Unix.tar.gz
sh ./install.sh --install
# Restore:
sh ./install.sh --restore
```
